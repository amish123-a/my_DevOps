# Ювелирный онлайн-магазин (Jewelry Online Store)
## Описание проекта
Веб-приложение для интернет-магазина ювелирных изделий премиум-класса.
Платформа предназначена для просмотра каталога украшений, фильтрации по
металлам и драгоценным камням, управления корзиной и оформления заказов.
## Основной функционал (0.1.0)
- Интерактивный каталог товаров с категориями (Кольца, Серьги, Подвески).
- Подробная карточка изделия (металл, проба, вставки, размеры).
- Корзина покупок и оформление заказа.
